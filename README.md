# Portfolio Website — Assignment Three

## Project Description
This is my personal portfolio website developed for my CSN 1101 assignment at KCA University. It showcases my projects, skills, services, and contact information.

## Project Links
- **GitHub Repository:** https://github.com/EMMANUELREGE/PORTFOLIO-ASSIGNMENT
- **Live Website (Vercel):** https://portfolio-assignment-emz6.vercel.app
- **Live Website (GitHub Pages):** https://emmanuelrege.github.io/PORTFOLIO-ASSIGNMENT/

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub REST API

## Live GitHub Data
The website uses the JavaScript Fetch API to retrieve public repositories from my GitHub account. The repository names, descriptions, programming languages, and links are displayed dynamically on the portfolio website.

## Security
- The GitHub API request uses HTTPS.
- No API keys or secrets are required for this public repository request.
- `textContent` is used to display dynamic text safely.
- External repository links use `rel="noopener noreferrer"`.

## Performance Optimization
- Used a responsive CSS Grid layout for project cards.
- No image elements were found in the current HTML file, so image lazy loading was not applicable.
